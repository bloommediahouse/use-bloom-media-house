# Bloom Media House — Website

Animated one-page website for Bloom Media House: custom websites for small businesses in the US.

- `index.html` — the full site (HTML, CSS and JS in one file)
- `img/` — official logo files and the Bloomy flower used for the hover spin

Open `index.html` in a browser to preview. Any static host (Netlify, Cloudflare Pages, GitHub Pages) can serve it as is.
